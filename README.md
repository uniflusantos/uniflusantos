## Hello there 👋

I'm a computer science undergraduate doing research on nuclear and condensed matter physics, ranging from the experimental side to machine learning and computer vision applications.


I work on a daily with:
- 🔬 Automation of data acquisition systems on measurement instruments.
- ☢️ Simulation of radiation damage in materials, as well as TCAD device modelling.
- 💻 Linux infrastructure, distributed systems, machine learning and computer vision.
